# 現有策略評估與兩項新增策略提案

評估日期：2026-10-06。範圍是首頁目前顯示的五個策略圖層，以及與它們相關的策略模組、行情與回測路徑。

前半部保留實作前的程式規則評估；實作結果見文末。尚未執行真實行情的樣本外績效研究，以下門檻都是待驗證的起始假設，不能據此認定勝率、報酬或策略間的相關性。

## 現況判斷

首頁五個圖層由 `app/features/home/strategy-overlays.ts` 計算；回測 registry 目前有八個模組，包括 RSI 超跌回歸、Supertrend 動能、日線爆量、加密貨幣波段及短線動能爆發。新增策略應補足交易情境，避免重做既有的突破或回踩策略。

| 首頁策略 | 目前圖表判斷 | 評估與優先改善 |
| --- | --- | --- |
| 吃大魚 2.0 | MACD 金叉且收盤高於 EMA200 × 0.98，或 Supertrend 翻多；翻空顯示出場 | 可作趨勢訊號核心。EMA200 條件只限制 MACD 分支，Supertrend 分支可能在 EMA200 下方觸發；盤整時可能反覆翻向。股票雷達另有通知品質篩選，不能將原始圖表觸發與合格通知混為一談。 |
| 極值反彈 | 近期觸及布林外軌，RSI 從 15 以下回升／85 以上回落；EMA200 用於標示順逆勢 | 門檻極端，訊號少有其規則原因。逆勢反彈可能繼續下跌；圖層沒有完整持倉、停損與獲利出場規則，名稱中的「高勝率」尚無本次績效證據。 |
| 趨勢追蹤 | 收盤向上穿越 MA20 進場，向下穿越出場 | 橫盤容易來回觸發。回測模組使用多因子評分，預設門檻 40，而站上 MA20 或 EMA26 已給 40 分，並不要求其他因子同時成立；與圖表穿越事件不同。 |
| 連續爆量 | 連續兩根成交量高於各自前五根均量的 1.5 倍 | 適合量能確認。沒有上漲、突破或多頭條件，連續下跌爆量也可能被標成進場；量能本身不能證明主力吸籌。回測另外添加 MA20、20 根持倉上限與停損出場。 |
| 量增未破 | 放量 1.5 倍，但最高價未超過前一根最高價 | 適合作警示。這裡的「前高」只是一根 K 的高點，不是長期壓力位；圖表是 WARNING，回測則另定義為放空情境，兩者用途不同。 |

### 需要先統一的地方

1. 圖表、回測與掃描器引用同一策略判斷核心，另外明確顯示「原始條件」「品質篩選」及「持倉出場」的差別。
2. 訊號須有做多／做空方向、是否已確認，以及是否僅為觀察；出場事件須對應該策略的持倉，不能把條件成立次數當成交易筆數或勝率。
3. 首頁的極值策略不是 registry 的 `rsi_mean_reversion`：後者以 RSI < 20 且低於 MA20 的 90% 進場，回歸 MA20 出場。不能用後者績效替代前者。
4. 圖表吃大魚使用共用 Supertrend，股票雷達使用 `bigFish.ts` 的獨立 Wilder ATR 與初始化規則；應逐根對照，不能先假設完全相同。
5. 首頁的圖層開關控制顯示。現貨自動交易引擎選用的是 `rsi_mean_reversion`，新增圖層或註冊模組不會自動讓它成為實盤策略。

## 提案一：波動收斂突破

- 建議代號：`volatility_squeeze_breakout`。
- 用途：找出波動壓縮後的向上啟動，補足既有均線／Supertrend 趨勢跟隨。
- 第一階段：台股、美股日線，只做多；加密貨幣 4 小時可另做研究，不共用未驗證績效。
- 圖表短名：`收斂突破`；狀態文字為「收斂觀察」「突破進場」「突破失敗／出場」。

John Bollinger 將 BandWidth 用於辨識波動收斂，並說明收斂後等待突破的研究方向；收斂本身不能決定方向。以下具體規則是本系統研究提案，並非照搬官方策略。[Bollinger Bands 規則](https://www.bollingerbands.com/bollinger-band-rules)、[官方確認突破方法說明](https://www.bollingerbands.com/_files/ugd/58be43_d09c50b6e8ea4afd9af0523ef94de876.pdf)。

### 起始規則

1. 使用 BB(20, 2)，帶寬為 `(上軌 − 下軌) / 中軌`。各根帶寬與其之前 120 個有效帶寬值比較；連續三根位於第 20 百分位以下，標記為收斂觀察。這是標的自己的歷史相對門檻，不用固定帶寬套全部股票。
2. 觀察成立後五根內，已收盤價格首次同時高於當根布林上軌與前 20 根最高價，且帶寬比前根擴大。
3. 當根量須達前 20 根均量的 1.5 倍；均量與前高均排除當根。
4. 訊號收盤距離前高超過 ATR14 一倍則略過，避免以同一規格追逐過度延伸的突破。
5. 以訊號下一根開盤模擬成交；開盤距離突破位仍須符合追價上限，不符則取消待成交進場。

### 出場與風險

- 初始停損距離採訊號根 ATR14 的兩倍；成交後以實際成交價建立停損線。
- 進場後前三根若收盤跌回固定的突破位以下，視為突破失敗出場；其後以收盤跌破前十根低點作結構出場。收盤出場在下一根開盤成交，盤中停損由引擎處理。
- 觀察五根內未突破則失效，不能永遠沿用很久以前的收斂狀態。
- 起始暖機至少 150 根，用於 BB、歷史帶寬百分位及 ATR；參數改大時暖機需求同步增加。
- 主要風險是假突破、股票跳空、停損滑價。與既有波段／動能策略仍可能同時虧損，須用逐期淨報酬檢查增量價值。

## 提案二：盤整均值回歸

- 建議代號：`range_mean_reversion`。
- 用途：在弱趨勢且價格重返正常區間時交易反彈，補足現有趨勢與極端超跌訊號。
- 第一階段：台股、美股日線，只做多；優先研究成交活躍的股票與 ETF。
- 圖表短名：`區間回歸`；狀態文字為「盤整觀察」「回歸進場」「均值出場／區間失效」。

ADX 常用於衡量趨勢強度，低於 20 可作弱趨勢候選、20–25 屬模糊區，但不能保證價格一定橫盤。布林下軌觸碰也不足以單獨確認買點，因此提案要求價格重新收回帶內。[Fidelity ADX 說明](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)、[Bollinger Bands 規則](https://www.bollingerbands.com/bollinger-band-rules)。

### 起始規則

1. ADX14 連續三根低於 20，且 MA20 相對五根前的變化絕對值不超過當根 ATR14 的 0.5 倍，才視為盤整候選。
2. 前根收盤低於其布林下軌，當根已收盤重新站回當根下軌之上，但仍低於 MA20。
3. 前根 RSI14 低於 35，當根 RSI 比前根回升，確認弱勢暫時改善；不必等到 RSI15 的極端行情。
4. 若同標的已處於有效的收斂突破觀察狀態，略過區間買點，避免在波動可能擴張前押注繼續盤整。
5. 下一根開盤才成交，進場時的固定 MA20 目標扣除預估來回成本後，至少有初始風險距離的 1.2 倍，否則取消進場。

### 出場與風險

- 初始停損距離採訊號根 ATR14 的 1.5 倍，以實際成交價建立；MA20 目標採訊號根快照，避免目標隨價格下跌持續降低。
- 收盤達到固定 MA20 目標時排入下一根開盤出場，首版不使用會引入同根先後順序爭議的盤中限價獲利模型。
- 持倉十根仍未達目標則出場；ADX 升至 25 以上且負向 DI 高於正向 DI，視為下跌趨勢形成，亦排入出場。
- 起始暖機至少 150 根，包含 ADX 穩定裕度與共用收斂觀察判斷。
- 主要風險是盤整突然轉為單邊下跌；ADX 有延遲，仍需初始停損。價差很窄時成本容易吃掉毛利。

## 系統接入與驗證規格

1. 先統一現有圖表／回測的策略定義，再新增兩個純策略模組與可重用的 BB、ADX／DI、帶寬百分位快取，避免在 UI 另寫判斷公式。
2. 現有 `StrategyAction` 只有 `stopLossPct`，引擎以成交價的百分比設定固定停損。若要忠實實作上述 ATR 絕對距離、固定目標與突破位，須保存訊號快照並在成交時驗證跳空與建立價位，不能直接稱現有百分比停損就是兩倍 ATR。
3. 股市研究先使用既有日線歷史路徑。它與首頁行情路徑不同，不會用即時報價覆寫最後一根；公司行動與 OHLC 復權一致性仍須確認。短週期股票先完成交易時段聚合與獨立回測資料路徑，才能沿用策略。
4. 依時間切分研究／驗證／最後保留樣本，參數只在研究段挑選；至少跨上漲、下跌與盤整區間，並檢查分標的穩定性。可用前 60%／中間 20%／最後 20% 作起始分割，比例本身不是績效保證。
5. 使用下一根開盤成交、跳空停損與交易成本。台股稅費、美股成本與加密貨幣交易費分開設定；若研究合約另納入資金費率。不能用單一預設成本代表所有市場。
6. 評估扣成本後期望值、最大回撤、交易數、持倉時間與報酬相關性；與買入持有及現有策略組合比較。同根多策略進場只占同一標的風險額度，不能各買一份而不計總曝險。
7. 先提供圖表、回測與模擬紀錄。是否接入排程通知或自動交易另依使用者指定；新增 registry 不改動現有開倉開關。

建議先研究「收斂突破」，再研究「區間回歸」。前者更貼近目前股票雷達的趨勢用途；後者補足盤整情境，但需要額外驗證市場狀態誤判造成的虧損。

## 已實作（2026-10-07）

- `volatilitySqueezeBreakout.ts` 與 `rangeMeanReversion.ts` 已註冊；首頁增為七個圖層，新策略只接受台股／美股日線。
- 新增吃大魚與極值反彈的持倉模組供回測。吃大魚與雷達共用 `analyzeBigFishAt`，圖表改用相同的 Pine 暖機及 Wilder ATR；極值策略增加回歸布林中軌及固定 5% 研究停損，不再使用尚未驗證的「高勝率」名稱。
- 圖表直接重用回測引擎與指標快取。趨勢追蹤採既有多因子評分；量增未破依同一條件顯示做空觀察。圖層開關只改呈現，不改交易歷史。
- 圖表以市場預設費率、5 bps 滑價、100 萬報價幣別的示意資金、1% 單筆風險、50% 部位上限重放；它不等於使用者帳戶。回測可調參數、資金與成本，設定不同時成交筆數可以不同。
- 風險式倉位按停損價差估算，費用、稅率及跳空會使總損失超過此風險百分比；新策略尚未接入帳戶級多策略風險分配。
- 只確認已收盤 K，排除 mock 與不合法 OHLCV；缺少 151／201 根等暖機資料或週期不支援時會顯示原因。股票提早收盤日保守等待至正常收盤時間；短週期行情的既有聚合來源限制仍存在。
- 訊號根保存絕對 ATR 停損距離、突破位、固定均值目標及成交界線。實際下一根開盤套用滑價後重新驗證；目標不足、超額追價或跳空失效時取消。兩個新策略禁止當根收盤成交。
- 區間進場額外要求實際成交價仍位於訊號下軌之上；區間出場使用固定目標，不隨均線降低。兩策略暖機依最終回看參數增加，資料準備與重放一致。
- 新回測可設定賣出交易稅率；台股預設一般股票 0.3%，ETF、當沖與特殊商品須手動調整。舊研究快照缺少此欄時沿用原先零稅率，不改寫既有結果。[證交所投資指南](https://www.twse.com.tw/zh/about/company/guide.html)、[ETF 交易規則](https://www.twse.com.tw/zh/products/securities/etf/overview/rules.html)。
- 訊號明細顯示做多／做空、平倉／回補、取消及等待確認。資料末端不假造平倉；保留完整訊號歷史，價格線段維持近期 160 根以限制繪製成本。
- 新策略只接入圖表及獨立回測，尚未啟用通知、Cron 或自動開倉；同標的多圖層不代表合併帳戶的多策略曝險已經通過驗證。

### 驗證與限制

- 34 項相關測試通過：包括獨立 BB／ADX 手算值、歷史百分位不讀未來、真實指標合成序列的兩策略進出場、假突破、跳空取消、固定目標、ATR 絕對距離、交易成本與現貨不透支，以及原吃大魚／波段／Vela 回歸檢查。
- 本機合成資料七圖層重放：500 根約 41ms、1,250 根約 61ms；這是 Node 計算耗時，不能當作 Cloudflare 或瀏覽器 GPU 效能保證。
- 正式建置通過；仍有原本的大型 chunk／空 API chunk 提示。全專案 TypeScript 檢查保留四項既有錯誤：兩處 Freqtrade 的 `D1Database` 型別、`debug-new-strategy.ts` 舊呼叫及 `scratch/test_api.ts` 路徑，本次沒有新增型別錯誤。
- 瀏覽器以合成資料確認七個開關、全關清空、新策略參數與強制下一根成交，以及明細定位及完整原因；這些確認不代表真實行情勝率已驗證。
