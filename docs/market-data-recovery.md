# 行情恢復與策略診斷

2026-09-10：檢查本機回測、潛力幣雷達、波段雷達與戰情室。

## 已確認原因與修正

- 本機波段與潛力幣資料表原本沒有掃描紀錄。Vite 不執行 Cloudflare 的 scheduled 入口；現在首次本機請求啟動獨立觀察排程，沿用本機 D1。波段每分鐘補一批，潛力幣每 15 分鐘收盤兩分鐘後掃描。關閉開發伺服器即停止；不啟動交易引擎，也不建立或發送 Slack 通知。
- 公開行情探測曾遇到 Bybit 憑證驗證失敗，Gate 可用。潛力幣改為整輪切換 Gate：交易對、BTC、K 線、成交額與掛單都使用同所，卡片顯示實際來源。舊研究只用原來源補算，不混用跨交易所報酬。保留憑證驗證。
- 歷史行情每頁明確限定 1000 根時間窗，避免 Bybit 倒序回傳最近資料而遺漏前段；Gate 不再同送互斥的時間與 limit 參數。回測每趟最多四頁，已收盤資料才入庫。
- 戰情室大盤行情增加逾時；前端改成上次請求完成後才安排下次更新，避免慢請求反覆被取消。
- 潛力幣預設展示全部已掃描標的；等待條件、已確認及過熱仍分開標示。回測零成交顯示原因提示，勝率及 PF 顯示「—」。

## CCXT 的角色

[CCXT 官方文件](https://docs.ccxt.com/docs/manual)提供 `loadMarkets`、`fetchTickers`、`fetchOHLCV`、`fetchOrderBook` 等統一介面，適合由本機 Docker／VPS 的資料收集服務使用。CCXT 本身不是獨立託管的歷史資料 API，資料完整性、可用週期與存取限制仍取決於交易所。

建議未來由 CCXT 收集與儲存歷史資料，網站繼續提供看板與研究介面。這次修正仍使用既有公開 REST 行情，尚未把網站行情層遷移成 CCXT；避免將資料恢復誤記為完成新服務整合。
