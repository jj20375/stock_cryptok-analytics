# 合約吃大魚 2.0：Pine 條件與合約風控

新增獨立策略 `futures_big_fish`。原本首頁吃大魚、兩個合約策略與已儲存的自動化授權保留。介面沿用現有表單與圖表元件。

## 條件

- ATR 10、Supertrend 4、MACD 12/26/9、EMA200，共用既有吃大魚純計算，沒有新增其他大週期進場濾網。
- 空手時：MACD 金叉且收盤高於 EMA200×0.98，**或** Supertrend 從紅變綠，做多進場。
- 已持有多單：Supertrend 為紅色即退出，依貼出的實際程式執行。這不是「只在剛翻紅時退出」。紅色中的 MACD 提早進場可能在下一根又出場。
- 合約版另外加價格硬停損，預設 5%、可研究 1～20%。合約數量依本金、成本及停損風險縮小；原 Pine 沒有價格停損，兩者不能視為完全相同的成交回測。
- 沒有固定 2R 目標、6 小時退出，也沒有獲利 3% 後保本。原貼文的保本功能僅存在註解；若加入須另建版本比較。
- 此版的合約回測、預覽及自動化都是 **1H**。截圖的 **15 分鐘** 尚未接入這個合約執行器，不能把截圖結果套到此版。

Pine `strategy()` 預設於收盤計算，市價委託在下一根可用時點成交；本系統回測也要求下一根開盤。[TradingView 官方說明](https://www.tradingview.com/pine-script-docs/faq/strategies/)。實際自動化在收盤檢查後以交易所當時行情市價委託，成交仍需對帳。

## 在哪裡選擇

1. `/crypto-futures` 上方自動化選單新增「合約吃大魚 2.0（Pine 條件／僅做多）」。固定採預設參數，只有使用者重新選擇、確認並儲存後才改策略。
2. Demo 預覽增加同名策略，以及 SOLUSDT、ADAUSDT；預覽不代表送單或啟用 LIVE。
3. 下方合約回測可選同名策略、標的與日期，調整硬停損；報告以「合約大魚」標籤、Supertrend 防守線與 EMA200 生命線呈現。
4. 標的已有其他策略部位或未確認委託時，沿用禁止切換策略的機制。原生停損、最多三筆及每筆名目本金 3～5% 等風控仍適用。

這份資料沒有證明吃大魚是高勝率策略。它可能依少數較長的獲利單抵銷較多虧損單；SOL 對成本敏感，保留期 20% 的淨損益也為負。趨勢回踩不足30筆、零成交策略不能用0%當勝率比較。

此為既有逐倉壓力模型，含費率／Mark Price及連敗冷卻，不是實際全倉帳戶績效。不同期間、15分鐘週期、原Pine下單單位及無硬停損設定可能產生不同結果。費率預留以24小時估算，並非持倉時間上限；較長持倉仍持續產生實際資金費率。
