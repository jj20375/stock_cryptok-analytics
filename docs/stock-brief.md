# 首頁選股的基本面與近期消息

在首頁選擇 US／TW，點選熱門標的卡或左側股票後，卡片下方的「基本面與近期消息」會自動切換。此功能只供查閱，不會改變技術面分數、策略訊號或自動交易設定。

## 資料來源

- 上市估值：證交所 `exchangeReport/BWIBBU_ALL`。
- 上櫃估值：櫃買中心 `tpex_mainboard_peratio_analysis`。
- 公司重大訊息：證交所 `t187ap04_L`、櫃買中心 `mopsfin_t187ap04_O`，列出最新批次中屬於該公司的公告。
- 台股營收／財報：沿用 `stockResearch` 的官方月營收及一般業綜合損益表。
- 上市公司英文簡稱：證交所 `t187ap03_L`，供英文新聞標題比對。
- 新聞：Yahoo Finance 個股 RSS，保留發布時間、標題及原文連結；不抓取文章全文。
- 美股估值：Yahoo Finance；若來源拒絕或缺資料則顯示未提供，目前未介接 SEC 財報。

## 顯示規則

- 估值日期、財報期間、消息發布時間與讀取時間分開標示。台股殖利率原始資料已是百分點；美股 Yahoo 比例轉成百分點。
- 台股 EPS 為年初至該季累計，單位為新台幣元；不能當單季 EPS。
- ETF／ETN 不套用公司財報；仍提供消息及個股新聞入口。基金淨值、持股與配息資料尚未介接。
- 只列近 30 天且有有效時間的新聞；台股需明確出現公司名稱、官方英文簡稱或台灣交易所代號，避免混入日本同代號公司。
- 重大訊息來源不是完整歷史查詢；沒有列出消息不等於沒有事件。金融、保險等非一般業財報可能缺漏。
- 切換股票會取消舊請求並清除舊畫面；資料讀取失敗不阻塞 K 線。

## 執行與驗證

`GET /api/stock-brief?symbol=2330.TW&market=TW` 需要既有登入 Session。只接受固定代號格式；不接受使用者指定外部 URL。

來源快取 5 分鐘，失敗 1 分鐘，官方財務沿用 15 分鐘快取。外部請求有逾時、本文大小與快取容量限制。沒有新增 API 金鑰或資料庫遷移。

驗證指令（Node 20）：

```sh
node --import tsx --test tests/stock-brief.test.ts
npm run build
```
