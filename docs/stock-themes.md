# 題材與財報

登入站內後開啟 `/stock-themes`，可依台股代號查官方營收及一般業累計財報，並瀏覽非凡首頁公開的《錢線百分百》單元標題。桌面與行動版導覽皆有入口。從題材中點股票可查財報，再前往個股分析或台股雷達核對技術條件。

## 資料與限制

- 來源不需額外金鑰、外部會員或付費服務。只讀非凡首頁可見的標題、節目日期與影片連結，不讀取會員圖卡、字幕或影片本文。
- 只顯示近 14 天可辨識日期的單元，去除重複標題與完整版；首頁不等於完整節目庫，單元數不等於市場熱度。
- 題材由標題中的明確關鍵字分類，股票依官方月營收公司名單比對。兩字簡稱僅接受分隔明確的名稱或括號股票代號，以降低一般用語誤配；因此會漏掉部分個股。
- 股票提及不代表公司實際受惠、來賓看多或建議買進，不自動延伸供應鏈名單。
- 證交所／櫃買中心月營收以新台幣千元計；一般業綜合損益表為年初至該季累計，EPS 以新台幣元計。上櫃財報的 `Year`、`Season`、`SecuritiesCompanyCode` 會轉成共用格式。
- 財報不包含金融、保險等其他業別，未提供歷史財報、現金流或估值。本版不能驗證題材受惠與營運趨勢，也不產生買賣評分、交易或通知。
- 出表日期是資料匯出日期，不是原始公告時間；不能將目前快照直接用於歷史回測。
- 各來源獨立降級，缺值不補零。超過 100 天的月營收與超過 270 天的財報提示落後；一般業未收錄不等於公司沒有財報。
- 固定來源請求逾時 12 秒，本文上限 4 MiB，拒絕重新導向；成功快取 15 分鐘、失敗快取 1 分鐘，僅 isolate 記憶體快取及請求合併，沒有歷史保存或跨 isolate 共享快取。
- 新頁面不呼叫 AI。使用既有「開始分析」時，才將該股官方財務與明確提及的公開標題交給既有 AI，要求標明資料限制，不得捏造籌碼或供應鏈證據。

## 驗證

使用 Node.js v20.19.6，執行：

```sh
node --import tsx --test tests/stock-research.test.ts tests/stock-research-access.test.ts
npm run build
```

測試涵蓋累計期間、單位、零值、負數、缺值、上櫃英文欄位、無效日期、來源降級、快取、標題去重與保守個股比對；不呼叫付費 AI 或交易服務。
